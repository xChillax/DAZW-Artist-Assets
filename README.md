# DAZW Artist Assets
Provided by yours truly, Chillax.

Also thanks to Dandy for making the palette tree design used for the palettes provided here.

This is an unofficial visual reference library of sprites and animation previews extracted from **Dead Ahead: Zombie Warfare** and **The Zombies**. It is intended to help community artists browse the game's assets for reference purpouses! Enjoy! :)

## What can I find here?
- `Dead Ahead Zombie Warfare/`:
  - `units/`: player units, zombies, marauders, support items.
  - `backgrounds/`, `map tiles/`, `cutscenes/`, `ui/`, and `fonts/`: HUD, world and level backgrounds, UI, fonts, etc.
  - `vehicles/`: buses, skins, parts, and other vehicles.
- `The Zombies/`: sprites version 0.952 (bike game)
  - `entities/`: player and zombies
  - `backgrounds/`, `hud/`, `cutscenes/`, `ui/`, and `fonts/`: HUD, props and level backgrounds, UI, bike HUD, etc.
  - `vehicles/`: car, trucks, etc.

You will find here pngs and gifs for easy access to anything you might be looking for.

You should find most stuff named properly, having gifs, and also folders for their animations where I saw fitting.

I also included palette files and previews of certain assets for easier usage! (such as the map tiles, and level backgrounds)

## How do I download a single folder?
You can use https://download-directory.github.io/

Just go to the folder you want, copy the URL from it, paste it on that site above and it will give you a zip of it.
